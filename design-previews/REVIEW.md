## Shared design rules used in every preview

- Mockup controls layout, atmosphere, and visual language.
- Uploaded FN monogram replaces every incorrect logo.
- Deep black `#03050B`, dark navy `#071329`, navy blue `#0A192F`.
- Electric blue `#0866FF` / `#168BFF` dominant, silver `#C7D5EA`, white `#F5F8FF`.
- Glassmorphism panels, thin blue borders, soft electric-blue shadows, holographic accents.
- Same female tech mascot and same FN holographic emblem on every page.
- Purple used only as subtle secondary lighting.

## Mobile-specific rules

- Genuine mobile-first composition, not a compressed desktop page.
- Compact FN logo navbar with hamburger menu.
- Bottom navigation bar where it fits the visual direction.
- Single-column glass cards, large readable typography, generous spacing.
- Touch-friendly buttons and no horizontal overflow.
